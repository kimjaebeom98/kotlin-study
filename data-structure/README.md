# data-structure — 자료구조

자료구조를 코틀린으로 직접 구현하며 익히는 곳.

> 표기 규칙(⭐ ⚠️ 🔍)과 문서 흐름은 [루트 README](../README.md#-문서-표기-규칙) 참고.

## 커리큘럼

**[CURRICULUM.md](CURRICULUM.md)** — Level 0(기초) → Level 1(선형 구조: 배열·문자열·연결 리스트·스택·큐·데크) → Level 2(해시테이블) → Level 3(비선형 구조: 트리·힙·트라이·세그먼트 트리·펜윅 트리·그래프) → Level 4(종합 응용: LRU 캐시 등). 주제마다 "개념 → 직접 구현 → 코틀린 표준 라이브러리 대응 → 인터뷰 문제" 순서를 지킨다.
